# Portfolio

Code source du portfolio de Théo Birost.

- `site-actuel/` : version actuelle du site.
- `versions/` : versions et essais précédents conservés pour référence.

La configuration locale, les secrets et le CV PDF contenant des coordonnées personnelles ne sont pas publiés. Pour que le lien de téléchargement fonctionne dans une installation locale, ajoutez votre propre PDF à `site-actuel/src/pdf/CV.pdf`.
